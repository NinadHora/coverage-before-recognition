# Contributing

Contributions, bug reports, and questions are welcome. Please open an issue first for larger changes so we can discuss the direction.

## How to contribute

1. Fork the repository.
2. Create a branch with a descriptive name.
3. Make your changes with clear commit messages.
4. Open a pull request against `main` with a short summary of what and why.

## Reporting issues

When opening an issue, please include:

- The command you ran.
- The full error message or unexpected output.
- The Python, PyTorch, and Ultralytics versions you are using.
- Your operating system and GPU model (when relevant).

## Code style

- Python 3.10 compatible.
- Prefer small, readable functions over clever one-liners.
- Add docstrings to new scripts explaining inputs, outputs, and usage.

# Contribuindo (português)

Contribuições, relatos de bugs e perguntas são bem-vindos. Para mudanças maiores, abra uma issue primeiro para conversarmos sobre a direção.

## Como contribuir

1. Faça um fork do repositório.
2. Crie um branch com nome descritivo.
3. Faça suas mudanças com mensagens de commit claras.
4. Abra um pull request contra `main` com um resumo curto do quê e do porquê.

## Reportando problemas

Ao abrir uma issue, por favor inclua:

- O comando que você rodou.
- A mensagem de erro completa ou saída inesperada.
- As versões de Python, PyTorch e Ultralytics em uso.
- Seu sistema operacional e modelo de GPU (quando relevante).

## Estilo de código

- Compatível com Python 3.10.
- Prefira funções pequenas e legíveis a one-liners sofisticados.
- Adicione docstrings aos novos scripts explicando entradas, saídas e uso.
