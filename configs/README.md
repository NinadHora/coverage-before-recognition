# Configs

Place the generated metadata and frame manifest files here:

- `ccv2_metadata.csv`: one row per video, with gender, age, Monk skin tone, country, Fitzpatrick type, and other annotations.
- `frame_manifest.csv`: one row per extracted frame with its subject ID and absolute path.

Both files are generated by `scripts/00_prep_metadata.py` from the CCv2 annotations JSON and the frames folder.

These CSVs are not tracked by git because they contain absolute paths that are specific to each environment.

# Configs (português)

Coloque aqui os arquivos de metadados e manifesto de frames:

- `ccv2_metadata.csv`: uma linha por vídeo, com gênero, idade, tom de pele Monk, país, tipo Fitzpatrick e outras anotações.
- `frame_manifest.csv`: uma linha por frame extraído com o ID do participante e o caminho absoluto.

Os dois são gerados por `scripts/00_prep_metadata.py` a partir do JSON de anotações do CCv2 e da pasta de frames.

Esses CSVs não são rastreados pelo git porque contêm caminhos absolutos específicos de cada ambiente.
